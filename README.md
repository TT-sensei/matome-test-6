# 6年生まとめテスト（小6算数）

6年生の算数まとめテスト対策として使える、A4・大問別特訓プリント集です。

- 全12単元・122問以上（問題シート12枚＋解答3枚＝全15ページ）
- 問題は端末に記憶されるので、開き直しても同じ問題が出ます（印刷したプリントと解答がずれる心配はありません）
- 「新しい数字で作り直す」ボタンで、全ての数値と比例・図形を再生成できます。押すと確認画面が出て、作り直した新しい問題がまた記憶されます
- 「赤字解答：ON/OFF」で解答の表示を切り替えて印刷できます
- 単元ごとの絞り込み、単元ジャンプ対応
- A4印刷／PDF保存対応（印字幅190mm）

単一HTMLファイルで動作し、外部サービスへの通信はありません。
